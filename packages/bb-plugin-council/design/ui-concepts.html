Verdict — by Grug, chief justice

Do not migrate now. Nobody has measured the speed gain. The costs are known: compatibility, reproducibility, CI, and releases. Keep pnpm, and test Bun on a benchmark branch first.

  • GrugBun speeds up installs, not builds. Our builds run bb, tsc, and vitest.
  • ArchitectThe migration changes how we install dependencies. We have no rollback plan or CI control for it.
  • DesignerNew contributors will not know which installer to use. Each directory needs one documented command.
Alternative: benchmark Bun on a branch. Switch only after it measures faster, installs native modules cleanly, and has a rollback plan.
Dissent: none. All active members ended opposed.
